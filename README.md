# KashmaMessenger

Отдельный сайт-мессенджер: регистрация **без email** (ник + пароль), история сообщений, live-доставка.
Без npm-зависимостей — только Node.js.

## Запуск

```powershell
cd C:\Users\kashm\OneDrive\Desktop\KashmaOS\kashmaMessenger
node server.js
```

Открой http://localhost:3000 — регистрируйся и общайся.

- Порт меняется переменной окружения: `$env:PORT=8080; node server.js`
- Слушает `0.0.0.0`, поэтому доступен в локальной сети по `http://<IP-ПК>:3000`.

## Как устроено

- `server.js` — HTTP-сервер: регистрация, вход, история, отправка, realtime через SSE.
- `public/` — фронтенд (index.html, styles.css, app.js).
- `data/store.json` — база: пользователи (scrypt-хэш пароля), сессии, сообщения. Не коммитится.

API:

| Метод | Путь | Назначение |
|-------|------|-----------|
| POST | `/api/register` | `{username, password}` → `{token, user}` |
| POST | `/api/login` | `{username, password}` → `{token, user}` |
| POST | `/api/logout` | выход |
| GET | `/api/me` | текущий пользователь |
| GET | `/api/history?room=` | история комнаты |
| POST | `/api/send` | `{room, text}` |
| GET | `/api/stream?room=&token=` | SSE: `message`, `presence` |

## GitHub Pages (работает между разными сетями без своего сервера)

GitHub Pages раздаёт только статику, запустить `server.js` он не может.
Поэтому фронтенд умеет два режима и **выбирает их сам**:

- **api** — если рядом доступен Node-сервер (`/api/health`). Им пользуются, когда сайт открыт с сервера.
- **ntfy** — иначе автоматически работают через публичный relay `ntfy.sh`.

Для GitHub Pages достаточно залить содержимое папки `public/` в репозиторий и включить Pages:
сообщения, история (~12 ч) и live идут через ntfy, разные сети и устройства — ок, сервер не нужен.

Как это работает в ntfy-режиме:
- «аккаунт» = ник + пароль, из них выводится секретное имя темы (`kashma-<ник>-<хэш>`);
- сообщения публикуются в тему по комнате, история читается через `?poll=1&since=`,
  live — через SSE, онлайн — по heartbeat каждые 20 сек.
- Кто знает ник и пароль — видит комнату. Отдельной регистрации на сервере нет (поэтому "лёгкая").

Принудительно выбрать режим можно в `index.html` перед `app.js`:
```html
<script>window.KASHMA_BACKEND = "ntfy";</script>   <!-- или "api" -->
```
Адрес Node-сервера (если фронтенд отдельно): `window.KASHMA_API_BASE = "https://сервер";`

## Ограничения

- Пароли хэшируются (scrypt), но передаются по сети — для боевого использования нужен HTTPS.
- Хранилище — один JSON-файл, рассчитано на небольшой круг друзей.
